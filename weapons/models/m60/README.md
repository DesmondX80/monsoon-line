# M60 model

Place Andy Woodhead's CC BY 4.0 M60 model here as:

```text
weapons/models/m60/m60.fbx
```

Download source:

https://sketchfab.com/3d-models/m60-machine-gun-1963-free-093e93399528434e9735539e25e51f8d

After adding the file, open the project in Godot and let it import the FBX.
The `MachineGun` script loads the model automatically when this path exists.

Recommended initial adjustments are available on the `MachineGun` node:

- `external_model_path`
- `external_model_enabled`
- `external_model_scale`
- `external_model_rotation_degrees`
- `external_model_position`

Attribution is required by CC BY 4.0 and is recorded in `docs/CREDITS.md`.
